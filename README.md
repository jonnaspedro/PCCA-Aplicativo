# PCCA Mobile

Aplicativo mobile da **PCCA — Plataforma de Compartilhamento de Conhecimento**, desenvolvido para proporcionar aos estudantes uma experiência mais prática, rápida e colaborativa para estudar, compartilhar conhecimento e interagir com outros alunos.

Diferentemente da versão web, o aplicativo foi desenvolvido com uma abordagem **mobile-first**, oferecendo recursos voltados à colaboração entre estudantes.

> **No site você encontra conhecimento. No aplicativo você constrói conhecimento junto com outros estudantes.**

## Objetivo

O PCCA Mobile tem como objetivo facilitar o acesso ao conhecimento acadêmico e incentivar a colaboração entre estudantes, criando um ambiente digital para estudo coletivo e compartilhamento de informações.

## Funcionalidades

- Acesso às disciplinas
- Criação e visualização de perguntas
- Respostas e interação entre estudantes
- Compartilhamento de resumos
- Compartilhamento de materiais
- Grupos de estudo
- Comunicação entre participantes
- Sistema de ajuda entre estudantes
- Perfil do aluno
- Notificações
- Organização de conteúdos por disciplinas
- Interface adaptada para dispositivos móveis

## Tecnologias

O projeto utiliza tecnologias modernas para desenvolvimento de aplicações mobile:

- **React Native**
- **Expo**
- **JavaScript**
- **Firebase**
- **Cloud Firestore**
- **Firebase Authentication**

## Estrutura do Aplicativo

O aplicativo é organizado em diferentes áreas para facilitar a navegação:

```text
PCCA Mobile
│
├── Início
├── Estudar
├── Criar
├── Perguntas
├── Resumos
├── Grupos
├── Notificações
└── Perfil
```

## Design

A interface do aplicativo segue a identidade visual da PCCA, utilizando uma proposta:

- Mobile-first
- Moderna
- Simples
- Responsiva
- Acadêmica
- Intuitiva
- Focada na colaboração

A identidade visual utiliza principalmente verde, branco e tons neutros, com componentes de interface como cards, botões, ícones e navegação inferior.

## Desenvolvimento

O PCCA Mobile faz parte do desenvolvimento da Plataforma de Compartilhamento de Conhecimento (PCCA) e tem como foco transformar a plataforma em uma experiência mais dinâmica e colaborativa para dispositivos móveis.

O projeto está em desenvolvimento e poderá receber novas funcionalidades, melhorias de interface e novas integrações.
